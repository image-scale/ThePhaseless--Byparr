# Goal

## Project
Byparr — a python project.

## Description
Byparr is a FastAPI-based web service that bypasses Cloudflare and similar anti-bot challenges. It uses a stealth browser (Camoufox) combined with an automated captcha solver to navigate through challenge pages, returning the resulting cookies, page content, headers, and user agent to the caller. The service supports proxy configuration via environment variables or per-request headers.
